Curated list of RAG Papers

Patrick Lewis @ NLP course UCL COMP0087

In 2020, Patrick Lewis co-authored a paper introducing RAG models that combine pre-trained parametric and non-parametric memory for language generation. These models achieved state-of-the-art results on several open-domain question-answering tasks. His research focuses on developing more powerful and efficient models that are robust and updatable, excelling in knowledge-intensive NLP tasks like question answering and fact-checking. I had the opportunity to attend his class at UCL which sparked my interest in his work and inspired me to consolidate all significant RAG papers.

  • RuleRAG - Introduces Rule-Guided RAG, using symbolic rules for in-context learning to enhance retrieval and generation accuracy. Read more
  • ChunkRAG - A chunk filtering approach for RAG systems, using semantic chunking and relevance scoring to improve response accuracy. Read more
  • AutoRAG Framework - Identifies optimal RAG modules for datasets and is available as a Python library. Read more
  • LONG²RAG - Offers a benchmark and metric for evaluating long-context retrieval and long-form response generation. Read more
  • EasyRAG - A lightweight RAG framework for network operations, offering accurate responses and easy deployment. Read more
  • Vision-based RAG (VisRAG) - Embeds documents as images for better data retention and retrieval, showing a 25–39% improvement over traditional text-based RAG. Read more
  • FunnelRAG - Uses a progressive retrieval method with coarse-to-fine granularity, reducing time overhead by 40%. Read more
  • CoFE-RAG - A full-chain evaluation framework for the RAG pipeline, providing insights into diverse data scenarios. Read more
  • RAG-based Spelling Correction - RAG-based approach for contextual spelling correction in e-commerce, enhancing accuracy. Read more
  • Multilingual RAG Benchmark (MIRAGE-Bench) - A multilingual RAG benchmark covering 18 languages, with proprietary LLMs showing top performance. Read more
  • Assessing RAG Models for Health Chatbots - Evaluation of 24 LLMs on medical data in Indic languages, revealing performance variability. Read more
  • Medical Multimodal RAG System - A multimodal RAG system for medical applications. Read more
